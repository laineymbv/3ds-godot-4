Class reference

Nintendo3DS

Access to 3DS hardware: the 3D slider, the stereo settings, 2D depth, and screen capture.

Inherits: Object

Nintendo3DS is available as the singleton Nintendo3DS on the 3DS. The stock editor doesn't know the class, so reach it through Engine.get_singleton and check Engine.has_singleton first:

var n3ds = Engine.get_singleton("Nintendo3DS") if Engine.has_singleton("Nintendo3DS") else null

In the fork's editor the class exists too and returns neutral values for the hardware queries, but set_depth and get_depth work there, so the depth you set is saved with the scene.

Stereo 3D: every Camera3D is rendered once per eye whenever the 3D slider is up. The eye separation and convergence come from the project settings rendering/3ds/stereo/max_separation (default 0.12) and rendering/3ds/stereo/convergence (default 3.0). set_stereo_separation and set_stereo_convergence override them for the current scene; a negative value restores the project settings.

2D depth: set_depth moves a CanvasItem in front of or behind the screen plane. See set_depth for the details.

Hardware: get_3d_slider gives the slider position from 0.0 (off) to 1.0. is_new_3ds tells you which console is running, so a game can scale effects down on the slower original. get_battery_level gives 0 to 5, and is_charging says whether the console is on charge.

Methods

float get_3d_slider()

Returns the 3D slider position, from 0.0 (off, one image) to 1.0 (full depth). Always 0.0 outside the 3DS.

Dictionary get_audio_stats()

Returns a dictionary about the DSP audio driver: active (bool), buffers_played (int), and last_peak (float, the loudest sample of the last buffer). Use it to check that sound is playing.

int get_battery_level()

Returns the battery level from 0 (empty) to 5 (full). Returns 0 outside the 3DS.

float get_depth(item: CanvasItem)

Returns the depth set on item with set_depth. An item that uses its parent's material reports the parent's depth. Returns 0.0 for an item with no depth.

float get_stereo_convergence()

Returns the convergence in use: the value set with set_stereo_convergence, or the project setting.

float get_stereo_separation()

Returns the eye separation in use: the value set with set_stereo_separation, or the project setting.

bool is_charging()

Returns true while the console is charging. Returns false outside the 3DS.

bool is_new_3ds()

Returns true on a New Nintendo 3DS or 2DS XL, and false on the original 3DS or 2DS.

void save_screens(dir: String)

Saves what the screens show after the current frame, as top_left.png, top_right.png (the two eyes) and bottom.png, into dir. Use it with OS.get_user_data_dir() to check the result of a change without a camera.

void set_depth(item: CanvasItem, depth: float, recursive: bool = true)

Places item in front of (depth > 0) or behind (depth < 0) the screen. The number is in pixels of disparity at full 3D slider, and the slider scales it. A depth of 0.0 puts the item on the screen plane, where all 2D items sit by default.

Each eye sees the item shifted sideways by half the depth times the slider, rounded to whole pixels so text and sprites stay sharp. The clip rectangle of a clipped item moves with it. Keep depths between about -6 and 6; larger shifts are hard to look at.

How it works: the item gets a ShaderMaterial with a stereo_depth parameter. If recursive is true, descendants without a material of their own use that material and share the depth. A descendant with its own material keeps it and sits at depth 0.0, unless you call set_depth on it.

Warning: if the item already has a different material, this replaces it. The editor's Stereo Depth row won't do that: it turns read-only in that case, so put a stereo_depth uniform on that material yourself.

void set_stereo_convergence(convergence: float)

Sets the convergence (the distance from the camera with no parallax) for the current scene. Pass a negative value to go back to rendering/3ds/stereo/convergence.

void set_stereo_separation(max_separation: float)

Sets the eye separation at full 3D slider, in world units, for the current scene. Pass a negative value to go back to rendering/3ds/stereo/max_separation.
